# P2 — تجربة التصعيد على الأجهزة (Runbook)

**الهدف:** إثبات بوابة P2 على أجهزة حقيقية:
- تنبيه P1 بلا ردّ يصل الوليّ الثاني خلال «النافذة + زمن التسليم المقيس»، ثم تتبعه رسالة SMS لجهة الاتصال.
- ردّ جهة الاتصال «1» بالـSMS يجعلها مالكة الحادث.
- لا يُغلَق P0 بشخص واحد دون التأكيد الثاني المؤقّت.
- ملف الشرطة: البصمات تطابق `manifest.json` على حاسوب، وشهادة الانقطاعات تذكر كل صمت.
- لا يحتوي إشعار ولا SMS ولا بطاقة ولا منشور على إحداثيات (عدا ملف الشرطة وصفحة المشاركة عمدًا) ولا على كلمة سر العائلة.

## 0) المتطلبات
- كل متطلبات P1 (`docs/runbooks/P1-local-trial.md` القسم 0) جاهزة، والخادم يعمل كما في القسم 1 هناك.
- متغيرات إضافية للخادم (في `core.env`، لا في المستودع):
  - `HIRZ_DATA_KEY`: 32 بايت عشوائية base64 (طريقة التوليد في runbook P1). لا تغيّرها بعد الحفظ.
  - `HIRZ_PUBLIC_BASE_URL`: عنوان نفق `cloudflared`، لتعمل روابط المشاركة.
- ثلاثة هواتف Android على الأقل:
  1. **المرافق** (الطفل): نسخة `play`، وضع «مرافق».
  2. **الأم (مالكة)** و**الأب (وليّ)**: نسخة `play`، وضع «وليّ». يمكن أن يكون أحدهما محاكيًا.
  3. **البوابة**: نسخة `gateway` (ملف `app-gateway-debug.apk` من CI)، فيها شريحة برصيد. لا تُثبَّت نسخة `play` عليها.
- رقم هاتف لجهة اتصال حقيقية (هاتف رابع أو هاتف شخص متعاون) يستقبل SMS ويردّ.

## 1) الإعداد
1. الأم: أنشئ دائرة، ادعُ الأب كوليّ، أضف «طفل» واربط هاتف المرافق برمز الربط (مع رمز إلغاء ورمز إكراه).
2. الأم → «الدائرة» → «جهات اتصال بلا تطبيق»: أضف الجهة برقمها ولغتها.
3. الأم → «رمز ربط بوابة الرسائل»؛ على هاتف البوابة: وضع «بوابة الرسائل» → أدخل الرمز → اقبل أذونات SMS. يظهر إشعار «بوابة الرسائل تعمل».
4. الأم → «كلمة سر العائلة»: احفظ كلمة، ثم «إظهار» (يطلب قفل الهاتف).
5. سجّل الساعة الدقيقة على كل هاتف (الفرق مع الخادم يؤثر على القياس).

## 2) التجارب (سجّل كل نتيجة كما حدثت، بما فيها الفشل)
1. **5 × P1 بلا ردّ من الوليّ الأول:** اجعل الطفل يخرج من مكان (أو ارسم مكانًا صغيرًا حوله ثم ابتعد 300 م). لا تلمس هاتف الأم.
   - قِس: زمن وصول الإنذار للأب منذ فتح الحادث (المتوقع ≈ نافذة P1 180 ث بعد التسليم أو 20 ث + 180 ث إن لم يصل الإشعار).
   - قِس: زمن وصول SMS لجهة الاتصال.
2. **3 × ردّ «1» من جهة الاتصال:** بعد وصول SMS، تردّ الجهة «1» (أو «١»). تحقّق أن الحادث يُظهر الجهة مالكةً عند الأم والأب.
3. **2 × إغلاق P0 بوليّ واحد:** اجعل الأم وحدها في دائرة تجريبية، اضغط SOS على المرافق.
   - مرة: الأم «إغلاق» ثم «تأكيد الإغلاق» → يُغلق.
   - مرة: الأم «إغلاق» ولا تؤكد → بعد دقيقتين يبقى الحادث مفتوحًا ويظهر «انتهت مهلة طلب الإغلاق».
4. **ملف شرطة واحد:** أثناء حادث فيه صمت (أطفئ بيانات المرافق 10 دقائق ثم أعدها)، الأم → «ملف الشرطة». انقل الملف من `Download/Hirz` إلى الحاسوب:
   ```bash
   unzip -o hirz-*.zip -d pack && cd pack && sha256sum positions.csv track.gpx incident.json completeness.txt
   ```
   قارن البصمات بما في `manifest.json`، وتحقّق أن `completeness.txt` يذكر الانقطاع بسطر `gap`.
5. **رابط مشاركة واحد:** الأم → «رابط مؤقت (ساعة)» → افتح الرابط من هاتف بلا التطبيق (متصفح فقط) → يظهر الاسم وآخر موقع وعمره ويتحدث كل 30 ث. ثم «إلغاء الرابط» → الصفحة تعطي 404.
6. **فحص المحتوى:** اقرأ إشعارًا واحدًا، SMS واحدة، البطاقة، المنشور (زر «منشور» ثم ألغِ قبل النشر)، وملف PDF: لا إحداثيات ولا كلمة السر.

## 3) التوثيق
اكتب `docs/evidence/P2-gate.md`: الأزمنة المقيسة (كل تجربة)، لقطات الشاشة، وكل فشل كما حدث. ثم:
```bash
git add docs/evidence/P2-gate.md && git commit -m "docs(evidence): P2 escalation trial"
```
