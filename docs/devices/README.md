# أوراق أوامر الأجهزة (Device SMS sheets)

المصدر الوحيد للأوامر هو `shared/src/commonMain/kotlin/dz/hirz/shared/devices/DeviceCatalog.kt`؛ هذه الأوراق تشرحها للإنسان.

| المستوى | المعنى |
|---|---|
| **مُختبَر (CERTIFIED)** | جرّبناه على جهاز حقيقي ونسخة firmware مكتوبة، وكل أمر في ورقته نجح. |
| **مدعوم (SUPPORTED)** | بروتوكوله في Traccar، والأوامر من التوثيق العام، **لم تُجرَّب بعد**. |
| **مرفوض (REJECTED)** | لا يمكن توجيهه إلى خادمنا. |

**حتى تجربة P3 على الأجهزة (`docs/runbooks/P3-device-trial.md`) لا يوجد أي جهاز مُختبَر.**

قواعد عامة:
- غيّر كلمة سر الجهاز الافتراضية **أولًا**. من يعرف رقم شريحة الجهاز وكلمته الافتراضية يستطيع توجيهه إلى خادم آخر.
- التطبيق يولّد كلمة السر الجديدة ويعرضها مرة واحدة؛ الخادم لا يحفظها. احفظها أنت.
- كل رسالة تُرسل من هاتفك أنت، بنقرتك، إلى رقم شريحة الجهاز.
- لا يُفعَّل الجهاز في حِرز إلا عندما تصل منه أول إشارة **بعد** طلب الإضافة (إثبات الحيازة).

الطرازات: [GT06N](gt06n.md) · [SinoTrack ST-901](sinotrack-st901.md).
