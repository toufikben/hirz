# GT06N (عائلة GT06) — مدعوم، غير مُختبَر

- **البروتوكول:** `gt06`، **المنفذ:** 5023 (TCP).
- **يرسل:** SOS، مستوى البطارية، انقطاع التغذية، تخزين المواقع عند انقطاع الشبكة.
- **لا يكشف:** نزع الجهاز.
- **كلمة السر الافتراضية الشائعة:** `123456`.

| الترتيب | الغرض | الرسالة | مُثبتة على firmware |
|---|---|---|---|
| 1 | تغيير كلمة السر | `PASSWORD,<الحالية>,<الجديدة>#` | لا |
| 2 | الخادم | `SERVER,1,<host>,5023,0#` | لا |
| 3 | APN | `APN,<apn>#` | لا |
| 4 | فاصل الإرسال | `TIMER,<ثوانٍ>#` | لا |
| 5 | رقم SOS (اختياري) | `SOS,A,<رقمك>#` | لا |
| 6 | الحالة | `STATUS#` | لا |

**ملاحظة بالفرنسية:** commandes issues de la documentation publique GT06 ; aucune n'est encore vérifiée sur un boîtier réel. Certains firmwares exigent le mot de passe dans chaque commande.

**نتائج التجربة:** تُكتب هنا بعد تجربة P3 (ردّ الجهاز حرفيًا، نسخة firmware، نجح/فشل).
