# Hirz P4 — Vehicles Implementation Plan

> **ملخص بالعربية:** المرحلة P4 تحمي **السيارة والدراجة النارية والشاحنة والحافلة خارج الخدمة**:
> - **التسليح:** يدوي بزر، وتلقائي بعد إطفاء المحرك N دقائق، وبجدول أوضاع. و**قيادة مفوَّضة** لمدة محددة (المالك أو سائق) تمنع الإنذار.
> - **القواعد الأربع:** `ARMED_MOVEMENT` (تحرك أو تشغيل والمركبة مسلّحة)، `TOWING` (سحب والمحرك مطفأ)، `POWER_CUT` (قطع التغذية)، `JAMMING` (تشويش). ومعها `PARKED_TILT` و`DOOR_OPEN_ARMED` و`ANTENNA_CUT` حين يرسلها الجهاز.
> - **قطع الوقود عن بعد بضوابط صارمة:** المالك فقط، بعد قفل الهاتف، بحادث سرقة مفتوح، والجهاز متصل، والمركبة شبه متوقفة. ولا أمر يبقى معلقًا لينفَّذ لاحقًا وهي مسرعة.
> - **التطبيق:** بطاقة المركبة (تسليح، تفويض، جدول، قطع/إعادة الوقود).
>
> **بوابة الخروج:** AC-22: تسليح سيارة ثم تحريكها = P1 خلال المدى المقيس، و**بلا إنذار** عند القيادة بتفويض. مقيس بسيناريوهات في CI، ثم على سيارة حقيقية.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An armed vehicle that moves, starts, is towed, loses power or is jammed raises an incident within a measured time; an authorized drive raises nothing; and the owner can stop the engine remotely only under safeguards that make a dangerous stop impossible by design.

**Architecture:** Vehicles reuse the unified core (design §12.1): the asset type selects the behavior profile, and a per-asset **mode** says what is expected now. A `VehicleModes` service resolves the current mode (manual switch, authorization window, schedule, auto-arm after ignition off) and records every switch in `mode_switches` (table exists since V1). A pure `VehicleRules` object evaluates the four rules on each signal with persisted per-asset state (`vehicle_rule_state`), feeding the existing `FindingRecorder`, so incidents, the ladder, SMS and exports are unchanged (AC-20). Engine cut goes through Traccar's command API behind a `RemoteEngine` service whose guards run server-side.

**Tech Stack:** P3 stack. New: Traccar commands API (`POST /api/commands/send`, types `engineStop`/`engineResume`); GT06 status-packet ignition (ACC) bit in the simulator.

**Spec:** `docs/05-hirz-design.md` §4.3 (vehicle rules), §4.4 (car/motorcycle/bus profiles), §10 (AC-22), §11 (P4 row), §12.1 (modes, links "drives", lifecycle `missing/stolen`), §12.2 (`PARKED_TILT`, `DOOR_OPEN_ARMED`, `ANTENNA_OBD_CUT`), §12.3.1 (remote actions: siren, fuel cut with safeguards). P3 ledger: `.superpowers/sdd/2026-10-29-P3-devices/progress.md`.

## Global Constraints

- Every P1–P3 Global Constraint applies (DTOs in `:shared`, no coordinates in pushes/SMS, duress silence, RED before GREEN in CI, rules are pure functions with replay scenarios).
- **Vehicle types:** `car`, `motorcycle`, `truck`, `bus` (bus uses the vehicle rules only while in mode `parked`; route rules are P9), `machinery`, `generator`.
- **Modes:** `armed`, `disarmed`, `authorized` (a drive window with an end time and who it is for), `maintenance`. Rules run only in `armed`, except `POWER_CUT`, `JAMMING` and `ANTENNA_CUT`, which run in every mode but drop to P2 outside `armed`.
- **Mode resolution order:** an active `authorized` window or `maintenance` → manual switch → schedule → auto-arm (ignition off for `autoArmAfterMs`). Every effective change is a `mode_switches` row with its reason (`manual`, `authorized`, `schedule`, `auto_arm`, `expired`).
- **Disarming or authorizing while a P0/P1 incident is open on the asset** answers 409 `incident_open`: a thief holding the owner's unlocked phone cannot silence an incident by disarming; the incident is closed under the P2 close policy first.
- **Starting thresholds** (in `RuleConfig`, to be measured): `autoArmAfterMs` 10 min; `armedMoveM` 50 m from the armed position with accuracy ≤ 50 m, or 2 consecutive fixes moving > 10 km/h; `armedP0SpeedKmh` 20 or `armedP0DistanceM` 500 → P0; `towingMoveM` 50 m with ignition off (or unknown) plus a vibration alarm or 2 moving fixes; `jammingSilenceMs` 3 min of total silence with the last report ignition on.
- **Engine cut safeguards (all required, checked on the server):** owner role only; device credential confirmed in the app; an open incident on the asset of rule `ARMED_MOVEMENT` or `TOWING`, or the asset lifecycle `missing`; the model's catalogue capability `engine_cut`; the Traccar device `online`; the last fix ≤ 60 s old with speed ≤ 20 km/h. A Traccar answer that the command was **queued** (HTTP 202, device offline) counts as failure and the queued command is deleted at once. `engineResume` needs owner role only. Every attempt, refused or sent, is audited and appended to the incident.
- **No new incident kinds for evidence:** findings use the existing `incidents` table; rule ids extend `RuleId`.

## Out of P4 (deliberate)

- **BLE auto-arm by the owner's phone distance and `KEYLESS_NO_OWNER`:** need a BLE presence channel in the companion and a tag; moved to P6 with the BLE relay work. P4 auto-arms on ignition-off time instead.
- **`LEFT_IN_VEHICLE`:** needs a child source linked to the vehicle and proximity without tracking the driver; moved to P9 with the "carried in" link work.
- **`FUEL_DROP`:** needs a fuel sensor model in the catalogue; added when such a device is bought.
- **Siren command:** catalogue capability exists only on some relays; added with the first certified model that has it.
- **Route mode for buses:** P9.

## Review Focus

1. **A GPS drift of 30–80 m while parked and armed (multipath under a building)** must not raise `ARMED_MOVEMENT`. Pinned by `parkedDriftDoesNotAlarm` (Task 3).
2. **An authorized drive that ends while still driving** must not raise an alarm at the window's end second; the vehicle is re-armed only after ignition off (auto-arm). Pinned by `authorizedWindowEndingMidDriveDoesNotAlarm` (Task 2).
3. **An engine-cut command when the device is offline** must never be left queued in Traccar to execute later at speed. Pinned by `queuedEngineStopIsWithdrawn` (Task 5).
4. **A heartbeat stream with ignition on and no fixes (parking garage)** while authorized must not look like jamming. Pinned by `garageWithIgnitionOnWhileAuthorizedIsNotJamming` (Task 3).
5. **Disarming from the app while a theft incident is open** must be refused. Pinned by `disarmDuringIncidentIsRefused` (Task 2).
