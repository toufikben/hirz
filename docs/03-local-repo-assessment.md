## 4. Supabase وRender: هل يصلحان؟
- **Supabase**: يصلح لـ PostgreSQL + PostGIS، والمصادقة، وRealtime، وتخزين الصور، وEdge Functions. أي أنه يصلح لـ"خادمنا" (الحسابات، الأصول، الحوادث). **لكنه لا يستطيع تشغيل Traccar ولا استقبال اتصالات TCP خام من أجهزة GT06.**
  - ملاحظة: المحاولة الثانية (`kidguard-ai-ultimate`) توقفت بسبب خطأ 401 في Supabase. كان ذلك خطأ إعداد مفاتيح وسياسات أمان (RLS)، لا عيبًا في Supabase.
- **Render**: خدماته تقبل HTTP(S) فقط على المنفذ العام. **لا يقبل منافذ TCP خام** لأجهزة التتبع. إذن يصلح للمرحل وواجهة API، ولا يصلح لـTraccar.
- **الخلاصة**: نحتاج **آلة افتراضية (VM) بعنوان IP عام** لـTraccar. الخيارات:
  1. VPS مدفوع (Hetzner/Contabo/OVH)، يحتاج بطاقة دولية.
  2. **Oracle Cloud Free Tier**: آلة ARM مجانية دائمًا بعنوان عام. يطلب بطاقة للتحقق فقط **[يجب التحقق من قبول بطاقات جزائرية]**.
  3. مزود جزائري بالدينار (حوالي 3,900 دج/شهر حسب بحثك السابق).
  4. للتجربة فقط: هاتف الطفل بتطبيقنا يرسل عبر HTTPS. هذا **يعمل مع Render/Supabase بدون VM**، لأن الهاتف لا يحتاج TCP خامًا. **هذا يفك الحصار جزئيًا الآن**: نبدأ بالهواتف، والمتتبعات بشريحة تنتظر الـVM.
